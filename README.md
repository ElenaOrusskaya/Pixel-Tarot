# Pixel Tarot

Пет-проект веб-приложения для раскладов таро
в стиле пиксельной ретро-игры.

## Технологии

React, TypeScript, Vite.
Планируется использование SCSS Modules и PixiJS.

## Запуск проекта

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm run build
```

## Текущее состояние

Создана начальная основа React-приложения.
